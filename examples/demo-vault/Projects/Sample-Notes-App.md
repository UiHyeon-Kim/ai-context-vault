# Sample Notes App 현재 요약

가상의 메모 앱 프로젝트. starter kit 시험용 예시이며 실제 프로젝트가 아니다.

## 현재 상태 (2026-01-05 기준)

- 구현 완료: 메모 목록·검색 화면
- 빌드·설치·실사용 검증: 모두 미수행 (가상 프로젝트라 빌드 대상이 없음). "구현 완료"를 "검증 완료"로 읽지 않는다
- 진행 중: 오프라인 동기화 설계

## 확정한 결정과 이유

| 구분 | 내용 |
|---|---|
| 사용자 결정 | 첫 버전은 로컬 저장만 지원한다 (일정 때문) |
| AI 제안(미확정) | 충돌 해결에 마지막 수정 우선 규칙을 쓰자 |

## 확인된 사실 / 추정

- 확인: 검색 화면은 한글 초성 없이 부분 일치만 지원한다 (상세: [[Projects/이력/Sample-Notes-App/2026-01-05-검색-검증]])
- 추정(미확인): 노트 1만 건에서도 검색이 느리지 않을 것이다

## 보류·금지 범위

- 보류: 클라우드 동기화 서버 선택 (사용자 승인 전까지 진행하지 않음)
- 금지: 사용자 데이터 외부 전송, 실제 계정 연결
