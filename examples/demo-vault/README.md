# Demo Vault

이 폴더는 starter kit을 시험하기 위한 **가상 데모 Vault**다. 실제 노트·회의·이메일·비밀값은 없다.
가상 프로젝트 "Sample Notes App"의 기록만 들어 있다.

## 읽는 순서

1. 이 README를 읽는다
2. 경로를 알면 해당 주제의 **현재 요약**(`context_role: current`)만 읽는다
3. 모르면 제목 검색 또는 [[_views/Home]]에서 찾는다. 필터 검색이 비면 필터 없이 다시 찾는다
4. 결정 이유·정확한 수치·실행 증거가 필요할 때만 상세 이력(`context_role: history`)을 읽는다

## 기록 규칙

- 현재 요약은 갱신하고, 날짜별 실행 로그는 `이력/`에 새 파일로 남긴다
- 수정 직전에 다시 읽고, 수정 후 재조회한다
- 사용자 결정 / AI 제안 / 확인된 사실 / 추정을 구별한다
- 쓰기 응답이 끊기면 대상 노트를 재조회하기 전에 같은 쓰기를 반복하지 않는다
