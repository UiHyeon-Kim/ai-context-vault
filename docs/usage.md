# 평소 사용하는 방법

이미 연결된 환경에서는 재설치 없이 원하는 AI에 작업 주제와 참고할 노트를 알려주면 됨
다른 AI로 이동하기 전 중요한 내용을 저장하고, 이동한 AI에서 다시 읽는 것이 핵심임

## 1. 작업 시작·재개

> AI-Vault의 ai-vault에서 README를 먼저 읽고, [주제]의 관련 현재 요약부터 찾아 읽어줘. 상세 이력은 근거가 필요할 때만 읽어줘. 확정한 결정과 남은 일을 짧게 정리한 뒤 [지금 할 일]을 이어서 진행해줘

예: `AI 도구 수집` 기록을 찾아, 관심 계정과 수집 기준을 이어서 정하기
검색 결과가 없으면 제목·경로로 다시 확인하고 없다고 단정하지 않도록 함

## 2. 기획하거나 결정한 뒤

> 방금 확정한 목표·범위·결정 이유·검토한 대안·완료 조건·남은 질문을 AI-Vault의 관련 기존 현재 요약에 갱신해줘. 긴 실행 기록은 별도 이력 노트에 저장하고 연결해줘. 아직 제안인 내용과 확정한 내용을 구별하고, 마지막 수정 후 다시 읽어 저장을 확인해줘

공통 지침이 적용되어 있어도 중요한 인계에서는 저장 위치를 명시하면 더 분명함
도구가 없는 채팅에서는 지침만으로 연결이 생기지 않음

## 3. 다른 AI에서 이어가기

> AI-Vault의 [노트 제목 또는 경로]를 읽고 이어서 작업해줘. 현재 목표·결정 이유·완료 조건을 먼저 확인해줘. 구현은 실제 저장소의 현재 코드와 규칙을 확인한 뒤 진행하고, 결과를 현재 요약에 갱신하고 상세 검증은 별도 이력으로 연결해줘

예: ChatGPT에서 기획 저장 → Codex에서 해당 노트 조회 → 구현·검증 → 결과 저장 → Claude에서 조사·검토
새 프로젝트 생성이나 전체 대화 복사는 필요하지 않음

## 4. 조사 결과 남기기

> [질문]을 공식 자료로 조사하고, 출처 링크·확인일·확인한 사실·추정·우리 작업에 적용할 점을 AI-Vault의 관련 노트에 기록해줘

오래된 조사 결과는 현재 사실로 단정하지 않고 원출처를 다시 확인함

## 5. dots에서 사용하기

사용 중인 dot 대화를 열고 같은 요청 문구를 사용함
연결된 AI-Vault 플러그인을 찾아 실제로 호출할 수 있어야 하며, dot의 자체 기억에만 남기는 것으로 대체하지 않음

> AI-Vault의 [노트]를 읽고 [조사할 내용]을 확인해줘. 현재 요약에 결과와 남은 질문을 갱신하고 상세 근거는 이력으로 연결한 뒤 재조회해줘. 다른 AI에서도 이어갈 예정이야

dots에 반복 작업을 맡기려면 대상·시간대·주기·알림 조건·결과 저장 위치를 별도로 정해야 함
이 저장소를 올리거나 연결 시험을 실행하는 것만으로 예약 작업이 만들어지지는 않음

## 기록이 길어질 때

현재 요약에 날짜별 로그를 계속 붙이지 않고 상세 이력으로 나눔
현재 요약 우선 검색이 비어 있으면 필터 없는 검색으로 기존 일반 노트도 확인함
구체적인 구조·검색 인자·전환 순서는 [노트 구조 안내](context-structure.md)를 참고함

## 잘 안 될 때

| 증상 | 먼저 확인할 것 |
|---|---|
| AI가 도구가 없다고 함 | 현재 채팅에 AI-Vault/Basic Memory 도구가 제공되는지 확인 |
| ChatGPT·dots에서 시간 초과 | Mac 잠자기 여부, 터널 상태, 플러그인 연결 확인 |
| 직접 취소하지 않았는데 취소 문구가 나옴 | 사용자 취소로 단정하지 않고 [오류 대응 절차](troubleshooting.md)에 따라 호출 경계와 저장 여부 확인 |
| 다른 AI가 결정을 모름 | 실제 저장한 노트 경로를 알려주고 최신 본문 재조회 |
| 저장했다는데 내용이 없음 | 실제 쓰기 도구 결과와 마지막 수정 후 재조회 여부 확인 |
| 비슷한 노트가 여러 개임 | 기존 노트를 검색하고 정본 링크를 확인한 뒤 필요한 부분만 갱신 |

실행 성공은 AI의 완료 문장만으로 판단하지 않고 저장된 내용 또는 도구 결과와 대조함
쓰기 오류·응답 손실 뒤에는 저장 여부가 미확인일 수 있으므로 같은 쓰기를 즉시 반복하지 않음
