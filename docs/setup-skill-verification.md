# 초기 설정 스킬 검증

확인일: 2026-10-30. **macOS의 실제 Codex CLI와 Claude Code에서 초기 설정 → 새 세션의 짧은 저장 요청 → MCP 재조회까지 확인했다.** 독립된 임시 환경에서 수행한 시험이며, 실제 사용자 설정에 설치한 결과는 아니다.

개인 대화·노트 원문·계정 정보·인증 로그는 이 문서에 포함하지 않는다. 시험에는 가상 결정과 임시 프로젝트만 사용했다.

## 검증 환경

| 항목 | Codex CLI | Claude Code |
|---|---|---|
| 클라이언트 | 0.160.0 | 2.1.292 |
| 모델 | `gpt-6-astra` | `claude-opus-5-5` |
| Basic Memory | 0.24.1 | 1.0.0 |
| 스킬 설치 위치 | 임시 프로젝트의 `.agents/skills/vault-setup/` | 임시 프로젝트의 `.claude/skills/vault-setup/` |
| 등록한 지침 | AGENTS.md | CLAUDE.md |

두 시험의 스킬 SHA-256은 `ae5926e0d3b2334be32f3bdd2ed513d9605a66f76757d9b5562778fe196d304e`다. Claude Code 시험에서는 `b4aa6db`의 스킬을 수정 없이 사용했다. Basic Memory 버전이 서로 다르므로 같은 버전 간 비교 시험은 아니다.

## 확인한 동작

| 확인 항목 | 결과 |
|---|---|
| 스킬 자동 발견 | 스킬 이름·경로를 직접 지시하지 않은 초기 설정 요청에서 두 클라이언트가 `vault-setup`을 선택했다. Claude Code는 시작 목록 등록과 `Skill` 호출도 확인했다. |
| 이름 선택·지침 등록 | MCP로 README를 읽은 뒤 `내 메모장`이라는 호칭을 임시 프로젝트에 연결하고 요청 시 저장 규칙을 등록했다. 기존 규칙 보존과 수정 후 재읽기를 확인했다. |
| 새 세션의 짧은 요청 | 프로젝트 ID·지침 경로·이전 대화 없이 “내 메모장에 기록해줘”와 가상 결정을 전달했다. 각 클라이언트가 올바른 임시 프로젝트를 사용했다. |
| 저장·재조회 | 금요일 오후 6시에 알림을 모아 본다는 가상 결정과 이유를 저장했다. MCP 재조회와 디스크 Markdown에서 같은 내용과 확인 표식을 확인했다. |
| README 조회 실패 | README를 읽지 못할 때 지침을 등록하지 않는 것을 확인했다. |
| 정리 | 임시 프로젝트·Vault·DB·인증 자료·실행 로그를 제거했다. 실제 Basic Memory 설정에 시험 프로젝트가 남지 않았음을 확인했다. |

## 실제 자료 보존과 한계

사용자 설정을 복사하거나 변경하는 설치 시험이 아니라 별도 설정·DB·Vault와 제한된 MCP 연결을 사용했다. 두 시험 모두 기존 클라이언트·Basic Memory 설정과 인증의 전후 해시가 같았고, 개인 Vault에 새 Markdown이 생기지 않았다.

Codex 시험은 보호 대상 323개 파일의 해시가 같았다. Claude Code 시험에서는 보호 대상 327개 경로 중 무관한 개인 노트 1개가 대기 중 변경됐다. 시험의 파일·MCP 호출 기록에는 해당 노트 접근이 없었지만 변경 주체까지 확인하지는 못했다. 따라서 전체 Vault가 불변이었다고 주장하지 않으며 해당 노트를 수정·복원하지 않았다.

임시 로그는 정리 요청에 따라 삭제했다. 이 문서는 관찰 결과 요약이며 원시 로그를 제공하는 재현 자료는 아니다. 당시 스킬 형식 검사와 단위 테스트 52개, diff 검사도 통과했다.

## 발견해 보완한 부분

- README 본문을 읽지 못해도 지침을 등록하던 경우를 막도록 초기 설정 중단 조건을 추가했다.
- 도구가 바로 보이지 않을 때 연결이 없다고 단정하지 않고 클라이언트의 도구 검색을 먼저 사용하도록 지침을 보완했다.
- 시험 환경의 스킬 로딩·MCP 권한 문제는 최종 시험 전에 바로잡았다. 파일 탐색으로 스킬을 읽은 실행은 자동 발견 성공에 포함하지 않았다.
- Basic Memory 1.0.0은 `bm_read`·`bm_write` 등 새 도구 이름을 사용하므로 시험용 허용 목록도 실제 도구에 맞췄다. 스크립트 호환성은 [별도 시험](basic-memory-compatibility.md)을 참고한다.

이전 행동 시험에서는 별도 에이전트로 초기 등록·기존 규칙 보존·동일 설정 재적용·호칭과 저장 방식 변경·대상 파일 선택·도구 부재 시 초안 유지를 확인했다. 이는 실제 Claude 모델 시험과 구분한다.

## 남은 검증 범위

- 웹·데스크톱 일반 채팅 및 Windows·Linux에서의 초기 설정 스킬 흐름
- 개인 전체 적용, 별칭 충돌, 잘못된 이름 입력, 중요 결정 자동 저장 정책
- 기존 노트 수정·인계 갱신, 의미 검색, 반복 실행 성공률

특정 버전과 요청 한 세트의 성공이며 모든 모델·표현·환경에 대한 보장은 아니다. 사용 방법은 [초기 설정 안내](agent-setup.md), 실사용 확인 절차는 [채팅 검증](chat-verification.md)을 참고한다.
