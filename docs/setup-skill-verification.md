# 초기 설정 스킬의 임시 환경 행동 검증

확인일: 2026-10-30 · 스킬 버전: `5b5572a`의 `skills/vault-setup/SKILL.md`
환경: macOS, Python 3.12, Basic Memory 0.24.1, 독립 Codex 에이전트

스킬의 문구 검사에 그치지 않고 별도 에이전트가 스킬을 읽어 임시 지침 파일을 편집하게 했다. 생성된 파일과 수정 전 사본을 비교해 이름 선택·등록·재적용·변경을 확인했다. 스킬 자체를 수정할 문제는 이번 사례에서 발견하지 않았다.

## 방법과 격리 범위

- 임시 폴더에 가상 Vault, `setup-test` 프로젝트, Basic Memory 설정·DB, 기존 규칙이 있는 `AGENTS.md`와 `CLAUDE.md`를 준비했다.
- 에이전트는 임시 프로젝트 목록과 README만 조회하는 CLI 래퍼를 사용했다. 래퍼는 실제 Basic Memory를 호출하되 설정 디렉터리와 프로젝트를 임시 경로로 고정하고 쓰기 명령은 허용하지 않았다.
- 성공 사례의 에이전트에는 실제 사용자 홈·설정·외부 MCP 접근을 금지하고 선택한 임시 지침 파일만 편집하게 했다. 연결 부재 사례는 도구를 제공하지 않았다.
- 다른 문맥의 에이전트에는 생성된 AGENTS.md와 조회 요청만 제공했다. 생성 스킬이나 이전 대화는 제공하지 않았다.
- 실제 사용자 지침·클라이언트 설정과 개인 Vault Markdown 총 317개를 해시로 비교했으며 내용 변경 0건이었다. 실제 Vault에는 이 시험 결과도 기록하지 않았다.

## 실행 결과

| 사례 | 관찰한 결과 |
|---|---|
| 초기 등록 | 호칭 `내 메모장` → 프로젝트 `setup-test`, 요청 시 저장 규칙을 임시 AGENTS.md에 등록 |
| 기존 내용 보존 | 기존 규칙 표식 유지, AI-Vault 블록 1개. 선택하지 않은 CLAUDE.md는 그대로 |
| 동일 선택으로 재실행 | AGENTS.md가 첫 생성본과 바이트 단위로 동일 |
| 이름·저장 방식 변경 | `작업노트`·중요 결정 기록으로 기존 블록만 갱신. 이전 호칭과 요청 시에만 저장 규칙 제거 |
| 연결 유지 | 임시 Basic Memory 설정 파일이 변경 전과 바이트 단위로 동일, 프로젝트 ID 유지 |
| Claude Code 대상 선택 | CLAUDE.md에 `내 메모장`·요청 시 저장 규칙 등록, 기존 Claude 규칙과 Codex AGENTS.md 보존 |
| 새 문맥에서 짧은 요청 | “내 메모장에서 이어서 하자”를 받은 별도 에이전트가 지침을 읽고 setup-test README 실제 조회, 파일 쓰기 없음 |
| 도구가 없는 경우 | 연결 미완료로 보고하고 초안만 제시. 기존 AGENTS.md는 변경하지 않음 |

표의 통과는 위 사례의 관찰 결과이며 모든 요청에서 같은 행동을 보장하는 평가 점수가 아니다.

## 시험 환경 구성 중 발생한 문제

초기 프로젝트 등록 시 임베딩 모델 다운로드가 네트워크 제한으로 지연돼 60초에 중단했다. 프로젝트 등록과 README 텍스트 조회가 가능함을 별도로 확인한 뒤 시험을 진행했다. 의미 검색·전체 색인 성공으로 해석하지 않는다.

CLI 래퍼의 초기 출력 옵션은 설치 버전에서 지원하지 않아 `--json`으로 수정했다. 이는 시험 도구 수정이며 스킬 수정은 아니다. 도움말 확인 중 격리 환경 변수를 빠뜨린 호출 한 건은 실제 Basic Memory 디렉터리 권한 변경 단계에서 샌드박스에 차단됐고, 격리 경로를 지정해 다시 실행했다. 이후 모든 시험 호출은 제한된 래퍼를 사용했다.

## 아직 확인하지 않은 것

- 실제 Codex·Claude 앱의 스킬 설치·자동 발견·자동 지침 로드. 이번에는 스킬과 지침 경로를 명시해 읽게 했다.
- 실제 Claude 모델의 행동. CLAUDE.md 작성 대상 분기는 Codex 에이전트로 시험했다.
- Windows·Linux·웹 계정 지침 적용과 실제 노트 쓰기 왕복
- 개인 전체 적용 범위, 충돌하는 별칭, 잘못된 이름 입력 등 추가 경계 사례

따라서 **임시 환경에서 스킬에 따른 지침 생성·갱신은 확인**, **모든 앱에 설치된 상태의 종단간 연결은 미검증**으로 구분한다. 실제 앱 시험 절차는 [채팅 검증](chat-verification.md), 사용 방법은 [초기 설정 안내](agent-setup.md)를 참고한다.
