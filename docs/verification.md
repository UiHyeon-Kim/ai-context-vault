## dots 실제 시험

1. 사용 중인 dot에 지정한 두 노트 읽기, 한글 검색, 인계 노트 끝에 검증 기록 추가와 최종 재조회를 요청함
2. dots가 `list_memory_projects`, `read_note`, `search_notes`, `edit_note`를 사용했다고 보고함
3. dots는 마지막 수정 후 재조회에서 고유 검증 표식이 정확히 한 번 존재한다고 보고함
4. Codex가 Basic Memory MCP로 같은 노트를 직접 읽어 새 섹션과 표식 한 건을 확인함

README 첫 읽기는 HTTP 409 / MCP 서버 초기화 필요 오류가 발생했고 같은 요청을 순차 재시도해 성공했다고 dots가 보고함
오류 메시지 이상의 내부 원인은 확정하지 않음
이번에는 별도의 새 키·터널·권한을 추가하지 않고 기존 연결을 사용함
단계별 수행 내용은 dots의 완료 응답과 저장된 검증 기록을 근거로 하며, Codex의 독립 조회는 실제 저장 여부를 대조한 것임

## 기타 확인과 한계

- Mac LaunchAgent 등록·시작, 프로세스 종료 후 자동 재실행과 연결 복구는 확인함
- 실제 Mac 재부팅·재로그인 실험은 별도 미수행
- ChatGPT·Claude 일반 채팅의 공통 지침 저장과 재조회는 확인함
- 명시적인 저장 요청 없이 모든 상황에서 자동으로 도구를 선택하는지는 검증하지 않음
- 전체 대화 실시간 동기화와 SNS 수집·GitHub 추천·새 주간 알림은 설정하지 않음
- 이 저장소의 설정 파일은 자리 표시자가 있는 예시이며, 별도 신규 환경에 그대로 배포해 시험한 결과가 아님

## 2026-10-06 현재 요약·상세 이력 분리 검증

- 개인 Vault의 기존 47개 Markdown을 조사하고 긴 인계 6개를 현재 요약과 상세 이력으로 분리함
- 원문 6개는 이력 조각을 합쳐 기존 본문과 완전 일치하는지 확인함
- 기존 10개 수정·새 17개 생성·나머지 37개 유지, 내부 wiki 링크 오류 0건
- Basic Memory에서 README·현재 요약 7개 재조회, 현재 요약 필터 검색 3건과 상세 이력 표식 보존 확인
- README와 공용 인계를 함께 읽는 파일 문자 수는 29,397→4,135자로 85.9% 감소함

위 수치는 당시 로컬 점검 기록이며 일반적인 토큰·요금 85.9% 절감 보장이 아님
2026-10-10에는 이 기록과 최신 Vault 규칙을 대조해 사용법·양식을 반영했으며 과거 앱별 연결 시험을 전수 재실행하지 않음
개인 원문·일회성 정리 스크립트·백업 파일은 게시하지 않음

## 2026-10-13 오류 대응 점검

- Basic Memory 0.22.1, FastMCP 3.3.1, MCP SDK 1.30.0, tunnel-client 0.0.15 설치 상태에서 확인함
- 로컬 터널 health·ready 응답과 control-plane poll 상태가 정상인 시점을 확인함. 프로세스 실행만으로 connector 전체 정상 여부를 판단하지 않음
- AI-Vault connector로 운영 README 읽기 → 필요한 규칙 편집 → 재조회를 수행했고 로컬 파일에서도 같은 변경을 확인함
- 설치 소스의 편집 함수만 메모리 안에서 검사해 같은 append를 두 번 실행하면 중복되고, 이전 문자열이 사라진 `find_replace` 재시도는 일치 개수 검사에서 중단되는 것을 확인함
- 저장소 문서에 기록 시점·출처·검증 단계 구분과 [오류 대응 절차](troubleshooting.md)를 보완함. 설치 패키지·서비스 설정은 변경하지 않음

직접 취소하지 않았는데 취소 문구가 반환된 간헐 오류는 이번 읽기·편집·재조회에서 재현되지 않았음
과거 실패 호출과 로컬 실행을 연결할 요청 ID가 없어 원인은 미확정이며, 현재 성공을 장애 해결이나 모든 앱의 재검증으로 확대하지 않음
