## dots 실제 시험

1. 사용 중인 dot에 지정한 두 노트 읽기, 한글 검색, 인계 노트 끝에 검증 기록 추가와 최종 재조회를 요청함
2. dots가 `list_memory_projects`, `read_note`, `search_notes`, `edit_note`를 사용했다고 보고함
3. dots는 마지막 수정 후 재조회에서 고유 검증 표식이 정확히 한 번 존재한다고 보고함
4. Codex가 Basic Memory MCP로 같은 노트를 직접 읽어 새 섹션과 표식 한 건을 확인함

README 첫 읽기는 HTTP 409 / MCP 서버 초기화 필요 오류가 발생했고 같은 요청을 순차 재시도해 성공했다고 dots가 보고함
오류 메시지 이상의 내부 원인은 확정하지 않음
이번에는 별도의 새 키·터널·권한을 추가하지 않고 기존 연결을 사용함
단계별 수행 내용은 dots의 완료 응답과 저장된 검증 기록을 근거로 하며, Codex의 독립 조회는 실제 저장 여부를 대조한 것임
