아래는 선택 당시의 비교와 근거이며 법률 자문이 아님. 공개 전에 각 조건 원문을 확인해야 함

## 이 저장소가 Basic Memory와 맺는 관계

- Basic Memory의 소스 코드·파일을 복사하거나 포함하지 않음
- 스크립트는 설치된 `basic-memory`를 **별도 프로세스(CLI·MCP stdio)로 호출**할 뿐이며 import하거나 수정하지 않음
- 따라서 이 저장소의 라이선스가 AGPL로 고정된다고 단정할 근거는 확인하지 못했음. 다만 Basic Memory를 수정해 네트워크 서비스로 제공하는 등 별도 상황은 AGPL 조건의 대상이므로 이 저장소의 범위가 아님

## 추천과 이유 (선택 당시)

**MIT**를 추천했고 채택함. 목적이 “다른 사람이 설치해서 쓰는 스타터킷”이고 코드가 작은 스크립트와 문서뿐이며 외부 도구와 프로세스로만 연결되기 때문임
판단을 바꿀 조건: 특허·기업 사용이 중요해지면 Apache-2.0, Basic Memory 코드를 포함하거나 수정하게 되면 AGPL 조건을 먼저 검토
