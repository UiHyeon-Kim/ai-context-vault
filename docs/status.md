# 기능 상태와 책임 구분

문서 점검일 2026-10-30. 아래 과거 실행 결과는 각 확인일의 기록이며 현재 버전의 성공으로 읽지 않음

## 편의 기능 현황

| 기능 | 현재 제공하는 것 | 확인한 범위·남은 일 |
|---|---|---|
| 부를 이름 선택·변경 | `vault-setup`이 호칭과 실제 프로젝트 대응을 지침에 기록하는 절차 | 10/30 격리 행동 시험에서 등록·재적용·변경 확인. 실제 Codex CLI의 스킬 자동 발견·새 세션 지침 적용도 확인. [시험 범위](setup-skill-verification.md) |
| 프로젝트 ID·폴더·커넥터 이름 일괄 변경 | 이름별 영향 안내만 있음 | 자동 변경 도구 없음. 호칭 변경과 별개 |
| 짧은 저장·재개·인계 요청 | 공통 지침과 요청 예시 | 실제 Codex CLI 새 세션에서 호칭에 맞는 임시 프로젝트 조회·저장·재조회 확인. 인계 갱신과 다른 클라이언트는 미검증 |
| AI·적용 범위·저장 방식 선택 | 초기 설정 스킬. 요청 시 저장 / 중요 결정 기록 선택 | 실행 프로그램이 아닌 AI가 수행할 절차, 웹 앱은 붙여넣기 경로 |
| 설정 미리보기·백업·병합 | `merge_mcp_config.py` 실행 도구 | 임시 설정에서 실행 검증. 사용자 설정은 이번 작업에서 미변경 |
| 연결 사전 검사 | `vault_doctor.py` 실행 도구 | 기존 단위 테스트·임시 환경 검사. 현재 실환경 전체 재점검 아님 |
| 요약 먼저 읽기·상세 이력 분리 | 문서·메타데이터·양식 | 검색 필터는 기존 데모로 검증. 자동 요약 서비스는 없음 |
| 선택형 노트 항목 | 결정·보류·금지가 있을 때만 기록하는 양식 | 문서 반영. 실제 제약·실패는 생략하지 않도록 안내 |
| 백업·복구·자동 실행 | 복구 안내·macOS LaunchAgent 예시 | 원클릭 설치·자동 백업 서비스·Windows/Linux 자동 실행 도구 없음 |

위 표는 현재 저장소에 있는 기능의 범위다. 파일 존재·형식 검사와 앱 설치·실사용 성공을 구분하며, 전체 설치를 자동 완료하는 설치 마법사는 제공하지 않는다

## 누가 무엇을 제공하나

| 기능 | 제공자 | 이 저장소의 몫 |
|---|---|---|
| 노트 색인·검색·읽기·쓰기·수정 (MCP 도구 23종) | **Basic Memory** (외부 도구, AGPL-3.0-or-later) | 없음. 사용 방법만 문서화 |
| Obsidian 편집 화면 | Obsidian | 없음 |
| ChatGPT용 보안 터널 | OpenAI tunnel-client | 프로필 예시만 제공 |
| 클라이언트 등록 명령 (`claude mcp add`, `codex mcp add`) | 각 앱 | 사용법만 안내 (문법은 `--help` 기준, 실행하지 않음) |
| 연결 설정 예시, 공통 지침, 운영 규칙 | 이 저장소 | **직접 작성** (문서) |
| 현재 요약 / 상세 이력 구조, 인계 양식 | 이 저장소 | **직접 설계** (메타데이터 `context_role` 규약 + 양식. Basic Memory가 자동 분류하는 기능이 아님) |
| 사전 검사 `vault_doctor.py` | 이 저장소 | **직접 구현** (읽기 전용) |
| 설정 병합 `merge_mcp_config.py` | 이 저장소 | **직접 구현** (미리보기·백업·원자적 쓰기·반복 안전) |
| 시험 재현 `demo_roundtrip.py`, `mcp_stdio_check.py` | 이 저장소 | **직접 구현** (Basic Memory를 호출하는 시험 도구) |

이 저장소는 새 메모리 제품, MCP 서버, 검색 엔진, 동기화 서비스를 만들지 않았음

## 지원 환경

문서·기록 양식·공통 지침은 운영체제와 무관하게 사용할 수 있다. 아래는 도구와 연결의 검증 범위이며 다른 환경에서 사용할 수 없다는 뜻은 아니다

| 구성·환경 | 검증 범위와 한계 |
|---|---|
| Markdown·기록 규칙·인계 양식 | Windows·macOS·Linux에서 사용 가능한 텍스트. 실제 AI 연결은 별도 |
| macOS + Basic Memory 0.22.1 | 스크립트·격리 데모·MCP stdio 직접 검증 (2026-10-22) |
| Python 3.11 / 3.12 / 3.14 / 3.15 (macOS) | 당시 단위 테스트 52개 통과. 스크립트는 Python 3.11 이상 필요 |
| Ubuntu·Windows | 2026-10-22 CI에서 단위 테스트와 Basic Memory 0.22.1 연동 시험 통과. 클라이언트 연결·실사용은 미검증, 셸·경로 조정 필요 |
| macOS LaunchAgent | macOS 전용 자동 실행 예시. Windows·Linux용 자동 실행은 제공하지 않음 |
| 다른 Basic Memory 버전 | 0.23.2는 당시 별도 시험했고 최신 버전 CI는 실험적. 모든 버전 호환 보장 아님 |
| AI 클라이언트 | 기존 앱별 연결은 [검증 현황](verification.md)의 날짜별 기록. 다른 MCP 지원 AI는 전송 방식·인증·권한이 맞아야 하며 각각 연결 시험 필요 |
| 초기 설정 스킬·짧은 요청 | [격리 시험](setup-skill-verification.md)으로 지침 생성·변경·보존 확인. macOS + Codex CLI 0.160.0 + Basic Memory 0.24.1에서 자동 발견·새 세션 적용·MCP 저장·재조회 확인. 다른 클라이언트는 미검증 |

## 알려진 문제와 우선순위

| 중요도 | 문제 | 사용자 영향 | 상태 |
|---|---|---|---|
| 높음 | 설정 예시에 `/ABSOLUTE/PATH`가 남은 채 쓰면 조용히 실패 | 설치 직후 도구가 안 뜸 | `vault_doctor.py`가 4종 예시 파일에서 검출, 병합 도구는 절대 경로를 강제 |
| 높음 | 기본(hybrid) 검색이 임베딩 모델을 못 쓰면 텍스트 색인이 있어도 0건 | 오프라인·차단 환경에서 “기록이 없다”고 오해 | 문서화 + 시험으로 재현. 현재 요약 검색 레시피는 `text`라 영향 없음 |
| 높음 | 새 Vault에서 색인 전 검색 0건 | 위와 같은 오해 | 문서화 (`troubleshooting.md`) |
| 높음 | `edit_note` 실패가 `isError: false`로 오고, 없는 노트에 `append`하면 새 노트가 만들어짐 | 실패를 성공으로 오인, 경로 오타가 조용히 새 노트가 됨 | 공통 지침·오류 대응에 규칙 추가, MCP 시험으로 두 동작 확인. 서버가 막아 주지 않음 |
| 높음 | 쓰기 응답 손실 후 재전송 시 중복 | 기록 중복·오염 | 규칙 문서화 + 확인 없는 `append` 반복 시 중복됨을 시험으로 확인 |
| 중간 | 로컬 검증 환경인 macOS가 CI에서 실행되지 않음 (비공개 저장소의 러너 사용량 배수 때문에 제외) | macOS에서만 생기는 회귀를 CI가 잡지 못함 | 로컬 macOS에서 직접 실행해 확인. 공개 후 macOS 잡 추가 검토 중(일정 미정) |
| 중간 | 검증한 Mac의 기본 python3가 3.9라 스크립트 실행 불가 | 첫 명령에서 막힘 | 안내 메시지 + 문서에 명시 |
| 중간 | 프로젝트 ID와 폴더·표시 이름 혼동 | 잘못된 프로젝트 조회 | `naming.md`, doctor가 불일치 검출. 문서의 표시 이름은 `AI-Vault`로 통일함 (2026-10-22). 커넥터 이름을 실제로 바꾸면 문서 호칭도 함께 바꿔야 함 |
| 중간 | 구현 완료와 검증 완료 혼동 | 미검증을 완료로 인계 | 인계 양식에 단계 표 추가 |
| 중간 | `~/.claude.json`은 앱이 계속 쓰는 상태 파일 | 통째 재작성 시 동시 기록 덮어쓰기 위험 | 병합 도구가 적용을 거부하고 `claude mcp add`를 안내 |
| 중간 | Basic Memory 버전에 따라 동작이 다름: 0.23.2는 임베딩 모델을 받지 못하면 `reindex --full`이 `Reindex failed`와 종료 코드 1로 끝남(0.22.1은 0, 텍스트 색인은 둘 다 완성). 새 `mcp` SDK(2.x)는 도구 결과 필드가 `isError`가 아니라 `is_error` | 자동화·스크립트가 업그레이드 뒤 오탐 실패 | 시험 스크립트가 두 버전을 모두 처리하고 판정 로직을 단위 테스트로 고정. CI의 최신 버전 잡이 이후 변화를 감시. 서버 동작(`Edit Failed` 응답, 없는 노트 `append`)은 두 버전이 같음 |
| 낮음 | 한글 제목의 permalink가 로마자로 변환 | 링크 가독성 | 문서화 |
| 낮음 | 첫 실행 시 임베딩 모델 다운로드 | 오프라인·차단 환경에서 지연·경고 | 문서화 |
