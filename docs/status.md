# 기능 상태와 책임 구분

기준일 2026-10-22. 아래 분류는 이 저장소의 실제 파일과 실행 결과로 다시 확인한 값임. 과거 문서의 기록(`verification.md`)은 그 시점의 사실이며 현재 성공으로 읽지 않음

## 누가 무엇을 제공하나

| 기능 | 제공자 | 이 저장소의 몫 |
|---|---|---|
| 노트 색인·검색·읽기·쓰기·수정 (MCP 도구 23종) | **Basic Memory** (외부 도구, AGPL-3.0-or-later) | 없음. 사용 방법만 문서화 |
| Obsidian 편집 화면 | Obsidian | 없음 |
| ChatGPT용 보안 터널 | OpenAI tunnel-client | 프로필 예시만 제공 |
| 클라이언트 등록 명령 (`claude mcp add`, `codex mcp add`) | 각 앱 | 사용법만 안내 (문법은 `--help` 기준, 실행하지 않음) |
| 연결 설정 예시, 공통 지침, 운영 규칙 | 이 저장소 | **직접 작성** (문서) |
| 현재 요약 / 상세 이력 구조, 인계 양식 | 이 저장소 | **직접 설계** (메타데이터 `context_role` 규약 + 양식. Basic Memory가 자동 분류하는 기능이 아님) |
| 사전 검사 `vault_doctor.py` | 이 저장소 | **직접 구현** (읽기 전용) |
| 설정 병합 `merge_mcp_config.py` | 이 저장소 | **직접 구현** (미리보기·백업·원자적 쓰기·반복 안전) |
| 시험 재현 `demo_roundtrip.py`, `mcp_stdio_check.py` | 이 저장소 | **직접 구현** (Basic Memory를 호출하는 시험 도구) |

이 저장소는 새 메모리 제품, MCP 서버, 검색 엔진, 동기화 서비스를 만들지 않았음

## 구현·검증 상태

| 항목 | 구현 | 검증 수준 | 비고 |
|---|---|---|---|
| 현재 요약/이력 구조 문서와 양식 | 구현됨 | 실제 검증됨 (2026-10-06 개인 Vault 전환 / 2026-10-22 데모의 필터 검색: 요약만·이력만) | 채팅에서 AI가 자동 준수하는지는 미검증 |
| 인계 양식의 현재 상태·보류/금지 범위·사실/추정 구분 | 구현됨 (2026-10-22). 양식·공통 지침·Vault README 양식에 반영 | 문서 일치는 테스트로 확인, 데모 Vault에서 읽기·검색 확인. 새 양식을 AI가 실제 채팅에서 채워 쓰는지는 미검증 | **개인 Vault 본문에는 아직 반영 안 됨** (승인 필요) |
| 사전 검사 도구 | 구현됨 | 실제 검증됨: 단위 테스트, 예시 파일 4종의 자리표시자 검출, **실제 설정 5종(Codex·Claude Code·Claude Desktop·LaunchAgent·터널 프로필)과 실제 Vault에 읽기 전용으로 실행해 오류 0건** | 키 값은 읽지 않음 |
| 설정 병합 도구 | 구현됨 | 실제 검증됨: 임시 파일에서 미리보기·적용·재실행·충돌·손상/비정상 구조·백업 복구·심볼릭 링크·CRLF·BOM | 실제 사용자 설정 파일에는 적용하지 않음 |
| Codex·Claude Code·Claude Desktop·ChatGPT·dots 연결 | 예시 구현됨 | 2026-10-04~05 개인 환경에서 실제 채팅 검증 (`verification.md`) | 이번 작업에서 재실행하지 않음 |
| MCP stdio 계층 (도구 목록·한글 검색·필터·읽기·쓰기·수정·재조회) | — | 실제 검증됨 (2026-10-22, 임시 데모, 11/11) | 채팅 속 AI의 동작과 별개 |
| GitHub Actions 단위 테스트 | 구현됨 (`.github/workflows/ci.yml`: Ubuntu·Windows × Python 3.11·3.13) | 실제 검증됨: 2026-10-22 첫 실행 4개 잡 통과. macOS는 러너 비용 때문에 제외하고 로컬에서 검증 | Basic Memory를 설치하는 시험은 CI에서 실행하지 않음 |

## 지원 환경

| 환경 | 상태 |
|---|---|
| macOS (Darwin 27.0) + Basic Memory 0.22.1 | 스크립트·데모·MCP stdio 직접 검증 |
| Python 3.11 / 3.12 / 3.14 / 3.15 (macOS) | 단위 테스트 34개 통과. 3.9(macOS 기본 `/usr/bin/python3`)에서는 스크립트가 안내 메시지를 내고 멈춤 |
| Python 3.11 / 3.13 (Ubuntu·Windows, GitHub Actions) | 단위 테스트 34개 통과 (2026-10-22 첫 실행, 4개 잡) |
| Windows | 단위 테스트는 GitHub Actions(windows-latest)에서 통과. **Basic Memory 연동(`demo_roundtrip.py`·`mcp_stdio_check.py`)과 실제 사용은 미검증**. 스크립트는 UTF-8 출력과 CRLF·Windows 경로 표기를 방어적으로 다룸. 문서의 셸 예시는 POSIX 문법 |
| Linux | 단위 테스트는 GitHub Actions(ubuntu-latest)에서 통과. **Basic Memory 연동과 실제 사용은 미검증** |
| ChatGPT / Codex / Claude 채팅에서의 지침 준수 | 2026-10 개인 환경 기록만 있음. 이번 작업에서는 채팅 연결을 새로 확인하지 않음 |

## 알려진 문제와 우선순위

| 중요도 | 문제 | 사용자 영향 | 상태 |
|---|---|---|---|
| 높음 | 설정 예시에 `/ABSOLUTE/PATH`가 남은 채 쓰면 조용히 실패 | 설치 직후 도구가 안 뜸 | `vault_doctor.py`가 4종 예시 파일에서 검출, 병합 도구는 절대 경로를 강제 |
| 높음 | 기본(hybrid) 검색이 임베딩 모델을 못 쓰면 텍스트 색인이 있어도 0건 | 오프라인·차단 환경에서 “기록이 없다”고 오해 | 문서화 + 시험으로 재현. 현재 요약 검색 레시피는 `text`라 영향 없음 |
| 높음 | 새 Vault에서 색인 전 검색 0건 | 위와 같은 오해 | 문서화 (`troubleshooting.md`) |
| 높음 | `edit_note` 실패가 `isError: false`로 오고, 없는 노트에 `append`하면 새 노트가 만들어짐 | 실패를 성공으로 오인, 경로 오타가 조용히 새 노트가 됨 | 공통 지침·오류 대응에 규칙 추가, MCP 시험으로 두 동작 확인. 서버가 막아 주지 않음 |
| 높음 | 쓰기 응답 손실 후 재전송 시 중복 | 기록 중복·오염 | 규칙 문서화 + 확인 없는 `append` 반복 시 중복됨을 시험으로 확인 |
| 중간 | macOS 기본 python3가 3.9라 스크립트 실행 불가 | 첫 명령에서 막힘 | 안내 메시지 + 문서에 명시 |
| 중간 | 프로젝트 ID와 폴더·표시 이름 혼동 | 잘못된 프로젝트 조회 | `naming.md`, doctor가 불일치 검출. 문서의 표시 이름은 `AI-Vault`로 통일함 (2026-10-22). 커넥터 이름을 실제로 바꾸면 문서 호칭도 함께 바꿔야 함 |
| 중간 | 구현 완료와 검증 완료 혼동 | 미검증을 완료로 인계 | 인계 양식에 단계 표 추가 |
| 중간 | `~/.claude.json`은 앱이 계속 쓰는 상태 파일 | 통째 재작성 시 동시 기록 덮어쓰기 위험 | 병합 도구가 적용을 거부하고 `claude mcp add`를 안내 |
| 낮음 | 한글 제목의 permalink가 로마자로 변환 | 링크 가독성 | 문서화 |
| 낮음 | 첫 실행 시 임베딩 모델 다운로드 | 오프라인·차단 환경에서 지연·경고 | 문서화 |
