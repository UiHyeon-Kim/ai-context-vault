# 한 번 설정하고 짧게 요청하기

“Vault에 기록해줘”라는 말을 어느 Vault에 어떤 방식으로 기록할지 알려주는 초기 설정입니다. Basic Memory 연결은 먼저 완료해야 합니다.

## 연결·지침·스킬의 차이

| 구성 | 하는 일 | 적용 시점 |
|---|---|---|
| MCP 연결 설정 | AI가 노트 검색·읽기·쓰기 도구를 호출하도록 연결 | 사용할 AI마다 연결 |
| 상시 지침 | Vault 대상과 짧은 요청의 의미, 기록 방식을 기억하도록 안내 | 사용할 범위에 한 번 등록 |
| `vault-setup` 스킬 | 사용자 선택을 확인하고 상시 지침을 기존 설정에 병합 | 최초 설정 또는 설정 변경 때 실행 |

`AGENTS.md`는 셸 명령어도 스킬도 아닌 지침 파일입니다. 파일명은 `Agent.md`가 아니라 `AGENTS.md`입니다. 스킬은 별도의 `SKILL.md`를 포함한 폴더이며 필요한 작업에서 불러오는 절차입니다. 초기 설정 스킬을 매번 실행할 필요는 없습니다.

## 먼저 선택할 것

- 사용할 AI와 적용 범위: 현재 프로젝트만 또는 개인 전체
- Basic Memory에 실제 등록한 프로젝트: 예를 들어 `ai-vault` 또는 연습용 `ai-vault-demo`
- AI에게 부를 호칭: 기본 `Vault`, 원하는 경우 `내 메모장`·`작업노트` 등. 호칭만 바꿔도 프로젝트 ID와 실제 폴더는 유지됨
- 저장 방식: **요청 시 저장(기본)** 또는 중요한 결정·인계도 기록

중요 결정 기록을 선택해도 전체 채팅 복사·백그라운드 동기화·주기 작업이 생기지는 않습니다. 실행 중인 AI가 지침에 따라 기록하는 방식입니다. 사용자별 Vault 이름은 팀 공용 지침에 무심코 넣지 말고 개인 범위를 선택하세요.

## 어디에 등록하나요?

| AI 환경 | 상시 지침 위치 | 적용 방법 |
|---|---|---|
| Codex | 프로젝트의 `AGENTS.md` 또는 Codex 홈의 개인 `AGENTS.md` | 선택한 파일의 기존 내용을 보존하며 Vault 블록 추가 |
| Claude Code | 프로젝트의 `CLAUDE.md` 또는 개인 `~/.claude/CLAUDE.md` | 선택한 파일에 같은 블록 추가 |
| 웹·데스크톱 채팅 앱 | 해당 앱이 제공하는 사용자 또는 프로젝트 지침 | 생성한 블록을 사용자가 등록하고 새 채팅에서 확인 |
| 그 밖의 AI | 해당 클라이언트가 지원하는 지속 지침 기능 | MCP 연결·지침 적용 범위를 확인한 뒤 등록 |

로컬 파일을 웹 채팅이 자동으로 읽는다고 가정하지 않습니다. 앱마다 지원 기능과 적용 범위가 다르므로 지침을 저장한 것과 실제로 읽은 것을 구분합니다.

## 초기 설정 스킬 사용

저장소의 [skills/vault-setup/SKILL.md](../skills/vault-setup/SKILL.md)를 제공합니다. 스킬 설치 위치와 호출 문법은 사용하는 AI의 공식 안내를 따르세요. 폴더 전체를 설치하며 기존 동명 스킬이 있으면 덮어쓰지 말고 비교합니다. 이 저장소에서는 스킬 파일 형식을 검사했으며 앱별 설치·자동 선택은 아직 검증하지 않았습니다.

임시 프로젝트에서는 이름 선택·등록·재적용·변경과 기존 지침 보존을 실제 에이전트 실행으로 확인했습니다. [시험 결과와 한계](setup-skill-verification.md)를 참고하세요. 실제 앱의 자동 발견·설치 성공과는 별개입니다.

공식 안내 기준으로 `vault-setup` 폴더를 복사할 위치는 다음과 같습니다. `~`는 사용자 홈입니다. 해당 앱 버전에서 위치를 인식하는지 확인하세요.

| 대상 | 현재 프로젝트만 | 개인 전체 |
|---|---|---|
| Codex | `.agents/skills/vault-setup/` | `~/.agents/skills/vault-setup/` |
| Claude Code | `.claude/skills/vault-setup/` | `~/.claude/skills/vault-setup/` |

설치 위치와 적용할 지침 범위는 별개입니다. 개인 스킬을 설치해도 이번 초기 설정은 특정 프로젝트에만 적용하도록 선택할 수 있습니다.

스킬을 설치하지 않아도 파일을 읽을 수 있는 코딩 AI에 다음처럼 요청할 수 있습니다. 먼저 저장소를 작업 폴더로 열거나 실제 파일 경로를 지정하세요.

> skills/vault-setup/SKILL.md를 읽고 Vault 초기 설정을 진행해줘. 사용할 AI는 Codex, 적용 범위는 이 프로젝트, 프로젝트는 ai-vault, 부를 이름은 내 메모장, 저장 방식은 요청할 때만으로 해줘.

설정 후에는 “내 메모장에 기록해줘”로 요청합니다. 나중에 바꾸려면 같은 스킬에 “호칭을 작업노트로 바꾸고 연결 프로젝트는 유지해줘”라고 요청하세요. 앱 목록의 커넥터 이름·실제 프로젝트 ID·폴더 변경은 별도입니다. [이름별 변경 범위](naming.md)를 참고하세요.

AI는 연결 상태와 기존 지침을 확인하고 선택한 범위에만 규칙을 병합합니다. 파일을 수정할 수 없는 웹 앱에서는 붙여넣기용 블록을 받습니다. 기존에 중요한 결정을 자동 기록하는 규칙이 있다면 중복 추가하지 않고 선택한 저장 방식으로 조정합니다.

## 설정 후 확인

새 채팅에서 “설정된 호칭·프로젝트·저장 방식을 알려줘”라고 요청한 뒤, 선택한 호칭으로 “연결 시험 결과를 내 메모장에 기록해줘”처럼 작은 기록을 남겨 확인합니다. 이어서 “방금 저장한 노트를 읽어줘”라고 요청해 저장 경로와 실제 본문을 대조합니다.

다른 AI에서도 같은 Vault 프로젝트를 선택해야 이어갈 수 있습니다. 규칙이 로드되지 않거나 도구가 없으면 설정 완료로 간주하지 않습니다. 실제 저장까지 검증하려면 [채팅 검증 절차](chat-verification.md)를 참고하세요.

## 양식은 필요한 만큼

기본은 요약·근거·다음 할 일입니다. 결정과 이유, 보류·금지 범위, 구현·테스트 상태는 해당 내용이 있을 때 추가합니다. 빈 제목을 채우려고 결정을 만들지 않으며, 실제로 있는 금지·미완료·실패 사항은 짧게라도 보존합니다.
