# 실제 채팅 연결 시험

각 AI의 실제 채팅에 아래 요청을 보냄
노트 이름과 확인 표식을 자신의 환경에 맞게 바꾸며, 기존 노트가 없다면 먼저 인계 노트를 준비함

```text
AI-Vault/Basic Memory의 ai-vault에서 README와 [인계 노트 경로]를 읽어줘
공용 컨텍스트라는 한글 질의로 검색해줘
검색 결과가 비거나 임베딩 오류가 나면 텍스트 검색으로 다시 찾아줘
1.0 도구는 mode=text, 0.x 도구는 search_type=text를 쓰되 실제 도구 스키마를 확인해줘
수정 직전에 인계 노트를 다시 읽고, 끝에 오늘 날짜와 사용 앱, 실제 호출한 도구,
성공·실패한 단계, 확인 표식 [이번 시험의 고유 표식]을 기록해줘
이미 같은 표식과 요청한 내용이 있으면 다시 추가하지 마
마지막 수정 후 같은 노트를 다시 읽어 표식이 정확히 한 번 저장됐는지 확인해줘
쓰기 오류나 응답 손실이면 바로 반복하지 말고 같은 노트를 읽어 반영 여부부터 확인해줘
읽기도 실패하거나 원래 쓰기가 서버에서 끝났는지 알 수 없으면 저장 여부 미확인으로 남기고 시험을 멈춰줘
도구가 없으면 미수행, 완료 여부를 모르는 오류이면 미확인인 단계와 이유를 알려줘
다른 곳에 대신 저장하거나 실행하지 않은 단계를 성공으로 쓰지 마
이 시험과 무관한 작업·예약은 변경하지 마
```

완료 응답을 받은 뒤 다른 클라이언트에서도 해당 노트를 읽어 표식을 확인함
설정 등록, 도구 목록 노출, 실제 읽기·쓰기, AI의 자동 지침 준수는 각각 별도 검증 항목임. 지침 준수와 인계는 [채팅 검증](../docs/chat-verification.md)의 절차로 확인함
재시도와 저장 여부 판정은 [오류 대응 절차](../docs/troubleshooting.md)를 참고함
