# 공용 컨텍스트 지침 예시

아래 항목을 해당 AI의 사용자 지침 또는 전역 작업 규칙에 기존 내용을 보존하며 추가함
지침 저장만으로 도구 연결이 생기지는 않으므로 MCP·플러그인 설정이 먼저 필요함

처음 등록할 때는 [초기 설정 안내](../docs/agent-setup.md)에 따라 대상 AI·적용 범위·Vault 프로젝트·저장 방식을 선택함. 아래 `ai-vault`는 선택한 프로젝트로 바꿈
“Vault에 기록해줘”는 현재 주제 저장, “Vault에서 이어서 하자”는 최신 요약 조회, “Vault에 인계해줘”는 다음 작업을 위한 요약 갱신으로 해석함. 대상이 모호할 때만 확인함

- 장기 작업의 결정·조사·인계는 AI-Vault/Basic Memory의 ai-vault 프로젝트를 사용한다
- 시작·재개 시 README의 짧은 운영 규칙을 읽고 관련 주제의 현재 요약부터 확인한다
- 경로를 알면 바로 조회하고, 모르면 제목 검색 또는 현재 요약 필터로 결과를 좁힌다
- 현재 요약 검색은 metadata_filters={"context_role":"current"}, page_size=3으로 시작한다
- 결과가 없거나 부족하면 필터 없이 일반 노트·제목·경로를 다시 찾는다 — 기존 미분류 노트를 기록 부재로 판단하지 않는다
- 그래도 비면 search_type을 text로 지정해 다시 찾는다 — 기본(hybrid) 검색은 임베딩을 쓸 수 없는 환경에서 텍스트 색인이 있어도 비어 있을 수 있다
- 상세 이력은 결정 이유·상충 내용·정확한 수치·실행 근거가 필요할 때만 읽는다
- 기본은 요청 시 저장이다. 사용자가 ‘중요한 결정도 기록’을 선택한 경우에만 중요한 선택·확정 방향을 결정 직후 관련 기존 현재 요약에 반영한다. 기존 노트가 없으면 Inbox에 출처와 확인 범위를 붙인다. 조회 요청만으로 새 기록을 만들지 않는다
- 바뀔 수 있는 내용은 미확정·제안·확인된 사실을 구별하고 확인일과 근거를 남긴다. 실행에 영향을 주는 현재 상태는 행동 전에 다시 확인한다
- 날짜별 긴 실행 로그는 같은 분류의 이력/주제/에 따로 남기고 현재 요약에는 링크를 둔다
- 현재 요약은 context_role: current, 이력은 context_role: history로 구별한다 — 이는 실제 검증 등급과 별개다
- 요약을 줄여도 결정 이유·실패·미해결·반대 근거·출처는 보존하며 요약과 이력이 불일치하면 갱신 범위를 알린다
- 목표·확정 사항·결정 이유·대안·근거·실제 완료 작업·검증·남은 질문·다음 할 일을 구분한다
- 양식의 제목은 선택 사항이다. 기본은 요약·근거·다음 할 일이며, 개발 인계에는 현재 상태의 구현·빌드/테스트·설치/실행·실사용 단계를 구별한다. 결정·보류·금지 내용이 있으면 반드시 보존하되 없는 내용을 만들거나 빈 섹션을 강제하지 않는다
- 날짜·사용 앱·실행 환경을 적고 사용자 발언·AI 제안·실행 결과를 구별한다. 과거 클라우드·다른 기기의 인계는 현재 이 기기 상태의 증거로 쓰지 않는다
- AI 초안과 사용자가 실제 제출한 원문은 출처와 상태를 구별해 보존한다. 제출 여부를 확인하지 않았다면 제출본으로 표시하지 않는다
- 빌드·설치·실제 기기 실행·QA는 각각 확인한 환경과 결과를 적는다. 한 단계의 성공으로 다음 단계까지 완료됐다고 쓰지 않는다
- 수정 직전 기존 노트를 다시 읽고 필요한 부분만 바꾸며 다른 AI의 기록을 보존한다. 대상 노트가 실제로 있는지 먼저 확인한다 — 없는 노트에 append하면 오류 없이 새 노트가 만들어진다
- 편집 도구가 isError 없이 ‘Edit Failed’ 같은 본문을 돌려줄 수 있으므로 응답 본문과 재조회로 성공 여부를 판단한다
- 마지막 수정 후 다시 읽어 저장을 확인하고 응답에 저장 위치를 알린다
- 단순 잡담과 전체 대화·비밀정보·불필요한 개인정보를 저장하지 않으며 사용자의 저장 금지·보류 요청을 우선한다
- 코드·ADR·백로그는 repo가 정본이며 확인한 repo·branch·commit과 검증 결과를 연결한다
- 도구가 없으면 미수행, 오류·응답 손실로 완료 여부가 불명확하면 미확인으로 알린다. 쓰기는 대상 재조회로 반영 여부를 확인하기 전 재전송하지 않으며 다른 서비스에 임의로 대체 저장하지 않는다
- 공유 범위는 실제 저장한 내용이며 전체 대화가 실시간 동기화된다고 설명하지 않는다
