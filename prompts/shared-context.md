# 공용 컨텍스트 지침 예시

아래 항목을 해당 AI의 사용자 지침 또는 전역 작업 규칙에 기존 내용을 보존하며 추가함
지침 저장만으로 도구 연결이 생기지는 않으므로 MCP·플러그인 설정이 먼저 필요함

- 장기 작업의 결정·조사·인계는 AI-Vault/Basic Memory의 ai-vault 프로젝트를 사용한다
- 시작·재개 시 README의 운영 규칙을 읽고 관련 노트를 검색한 뒤 최신 본문을 확인한다
- 중요한 결정과 인계가 생기면 관련 기존 노트를 갱신하고, 없으면 Inbox에 출처와 확인 범위를 붙인다
- 목표·확정 사항·결정 이유·대안·근거·실제 완료 작업·검증·남은 질문·다음 할 일을 구분한다
- 날짜와 사용 앱을 적고 사용자 발언·AI 제안·실행 결과를 구별한다
- 수정 직전 기존 노트를 다시 읽고 필요한 부분만 바꾸며 다른 AI의 기록을 보존한다
- 마지막 수정 후 다시 읽어 저장을 확인하고 응답에 저장 위치를 알린다
- 단순 잡담과 전체 대화·비밀정보·불필요한 개인정보를 저장하지 않으며 사용자의 저장 금지·보류 요청을 우선한다
- 코드·ADR·백로그는 repo가 정본이며 확인한 repo·branch·commit과 검증 결과를 연결한다
- 도구가 없거나 실패하면 미수행 범위를 알리고 다른 서비스에 임의로 대체 저장하지 않는다
- 공유 범위는 실제 저장한 내용이며 전체 대화가 실시간 동기화된다고 설명하지 않는다
