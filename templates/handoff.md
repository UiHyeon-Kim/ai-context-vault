# 작업 인계

이 파일은 현재 요약용 빈 양식이며 실제 작업 결과가 아님
아래 섹션은 선택형이다. 짧은 기록은 요약·근거·다음 할 일로 시작하고 해당하지 않는 표·제목은 생략한다. 결정과 이유·보류·금지 사항이 실제로 있으면 보존하며 빈 양식을 채우려고 만들지 않는다
`updated`는 편집일이고 재검증일이 아님. 실제 확인일은 본문에 따로 적음
대략 1~2천 자를 목표로 하되 중요한 조건·실패·미해결 사항을 길이 때문에 생략하지 않음
기록 환경: 날짜 / 사용 앱(예: Codex, Claude Code, ChatGPT) / 실행 OS

## 현재 상태

다음 AI가 가장 먼저 알아야 할 한 단락. 아래 단계를 구별해 적고 한 단계의 성공을 다음 단계로 확대하지 않음

| 단계 | 상태 (완료 / 미수행 / 실패 / 미확인) | 확인 환경·근거 |
|---|---|---|
| 구현 | | repo·branch·commit·미커밋 변경 |
| 빌드·테스트 | | 명령과 결과 |
| 설치·실제 실행 | | 기기·OS·버전 |
| 실사용(QA) | | 누가 무엇을 확인 |

## 확인된 사실 / 추정

- 확인된 사실: 출처 링크·확인일·확인 방법과 함께 적음
- 추정·미확인: 사실로 쓰지 않고 확인 방법을 함께 적음

## 보류·금지 범위

- 보류: 승인·정보가 올 때까지 진행하지 않는 일과 기다리는 대상
- 금지: 사용자가 하지 말라고 한 일(저장 금지, 변경 금지 대상, 외부 전송 등)
- 승인 없이 하지 않는 일: push·배포·공개·인증 변경 등
